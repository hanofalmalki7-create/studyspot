# StudySpot – Study Space Booking App

StudySpot is a simple web app for university students. A student can see the available study tables and rooms on campus, book one for a chosen time, and manage her bookings.

## Features (by user story)

| Sprint | User story | Feature in the app |
|---|---|---|
| 1 | US-01 | Login with university ID and password |
| 1 | US-02 | List of study tables and rooms |
| 1 | US-03 | Search by name and filters (type, size, floor) |
| 1 | US-04 | Book a space for 1 or 2 hours, with no double booking |
| 1 | US-05 | Space details: capacity, floor, facilities |
| 1 | US-06 | My Bookings: upcoming and past |
| 1 | US-09 | Cancel a booking (the time becomes free again) |
| 1 | US-10 | Free and busy time slots for each day |
| 1 | US-11 | Booking confirmation with a booking number |
| 1 | US-12 | Location of the space (building and floor) |
| 2 | US-07 | Reminder before a booking (15, 30 or 60 minutes) |
| 2 | US-08 | Rate a space after using it (1–5 stars) with an optional comment |
| 2 | US-13 | Average rating on every space, and sort by highest rating |
| 2 | US-14 | Notifications for booking confirmed, booking cancelled and reminders |
| 2 | US-15 | Profile: name and reminder time |
